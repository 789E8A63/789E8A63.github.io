Privacy Policy

This application is a personal rclone configuration used only by its owner to access the owner's own Google Drive files.

Data accessed: Google Drive file metadata and contents in the owner's account.

How data is used: Files are read and written only to provide local file access on the owner's computer. No data is collected, stored on any server, sold, or shared with third parties.

Storage: The OAuth token is stored only in a local configuration file on the owner's computer.

Revoking access: Access can be revoked at any time at https://myaccount.google.com/permissions.
